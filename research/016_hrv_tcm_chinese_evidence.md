# research/016 — 国内 HRV↔中医证型 真人验证文献证据（校准锚点来源）

> 目的：为 `estimate_tcm` 的 5 轴打分找**真人验证**锚点，把算法从「理论映射」升级为「证据映射」。  
> 背景：当前 5 轴公式（qi/liver/spleen/phlegm/balance）锚在 4-5 篇西方综述 + 教科书，缺真人校准。  
> 结论先导：HRV↔中医证型的相关性在国内**已大量验证**（疾病人群，数十~数百例，伦理审批）。  
> 关键缺口：这些多是**疾病人群**（冠心病/心衰/房颤），绝对值不能直接搬进健康向 App；  
> 可用的是**方向性 + 证型间排序**，绝对阈值需另找健康人群常模或自己 3 人验证。

## 一、已验证的方向性结论（可直接支撑 5 轴）

| 证型轴                    | 文献一致结论                      | 支撑论文                  |
| ---------------------- | --------------------------- | --------------------- |
| 气虚 (Qi def.)           | HRV(SDNN/RMSSD/HF)↓，迷走神经张力↓ | #3, #4, #6            |
| 阴虚 (Yin def.)          | RMSSD 通常最低；HRV 全面↓          | #3（阴虚质 RMSSD 17.4 最低） |
| 肝郁/气滞 (Liver qi stag.) | LF、LF/HF↑，交感相对亢             | #4, #6                |
| 血瘀 (Blood stasis)      | HRV 全面↓，混沌度低                | #1, #3                |
| 阳虚 (Yang def.)         | HRV 比气虚更低（气虚→阳虚进展递减）        | #2, #5, #6, #7        |
| 痰湿 (Phlegm)            | RMSSD 偏低                    | #3（痰湿质 22.8）          |

**重要方法论警示（给校准用）**：  
RMSSD↓ 是**虚/瘀的共有标记**，不是气虚专属——文献里 阴虚(17.4) < 血瘀(20.6) < 阳虚(22.3)≈痰湿(22.8) < 气虚(26.4) < 气郁(28.3) < 平和(29.6)。  
即：单看 RMSSD 分不出 气虚/阴虚/血瘀。要区分需更多 HRV 特征（LF/HF 辨阴虚/肝郁、SDNN 辨血瘀程度），而穿戴设备常只给 RMSSD。这是当前算法"5 轴"真实的方法学天花板。

## 二、精选论文清单（带真人样本 + 关键数值）

### #3 ★ 最直接可锚定阈值（给出分体质实测 HRV 绝对值）

**不同中医体质类型永久性心房颤动患者 D-二聚体水平与心率变异性及危险因素的相关性分析**

- 期刊：北京中医药，2024，doi:10.16025/j.1674-1307.2024.08.024
- 机构：中国中医科学院广安门医院；样本：150 例永久性房颤（2017–2020）
- 伦理：中国中医科学院广安门医院伦理委员会（2017-048-KY-02）
- 各体质 HRV 实测（金数据）：
  | 体质  | n  | SDNN(ms)   | RMSSD(ms) | 解读       |
  | --- | -- | ---------- | --------- | -------- |
  | 平和质 | 4  | 136.4±23.6 | 29.6±6.4  | 基准（近健康）  |
  | 气郁质 | 10 | 126.4±16.6 | 28.3±11.1 | 接近平和     |
  | 阳虚质 | 14 | 126.4±18.2 | 22.3±9.4  | RMSSD 偏低 |
  | 痰湿质 | 27 | 112.4±23.6 | 22.8±5.2  | RMSSD 偏低 |
  | 气虚质 | 61 | 96.4±12.7  | 26.4±8.1  | RMSSD 略低 |
  | 血瘀质 | 15 | 104.2±11.6 | 20.6±11.2 | RMSSD 低  |
  | 阴虚质 | 13 | 86.4±17.4  | 17.4±7.4  | RMSSD 最低 |
- 结论：气虚/阴虚/血瘀质 HRV 明显低于其他；阴虚、血瘀与 HRV 各指标均负相关。
- 用途：RMSSD 随"虚/瘀"加重递减的**排序锚点**。注意是房颤老年人群，绝对值偏低，用相对序不用绝对值。

### #4 ★ 含 50 例健康对照 + 气虚vs气滞方向锚点

**冠心病心绞痛气滞血瘀气虚血瘀患者与心率变异性分析的相关性研究**

- 样本：117 例气滞血瘀 + 104 例气虚血瘀 + **50 例健康人**；动态心电图
- 结果：病组 SDNN/RMSSD/PNN50/HF 低于健康对照，VLF/LF/LF-HF 增高；
  - **气虚血瘀组**：SDNN/RMSSD/PNN50/HF 明显降低 → 迷走神经张力↓；
  - **气滞血瘀组**：LF 及 LF/HF 相对增高 → 交感/迷走平衡失调（交感↑）。
- 用途：直接支撑「气虚↔迷走↓ / 肝郁(气滞)↔交感↑」两轴的**方向性**，且有健康对照基线。

### #1 胸痹（CAD）证型间 HRV 排序

**胸痹患者不同中医证型心率变异性分析**

- 收稿 2016-12；胸痹患者 vs 健康对照；HRV 时域
- 结果：各证型 SDANN 较健康对照显著降低（迷走活性降低为主）；  
  气阴两虚证 RMSSD 显著高于气虚血瘀/心血瘀阻证。
- 用途：证型间 HRV 排序参考。

### #2 非线性 HRV + 聚类客观化方法学

**基于心率变异性非线性分析的冠心病中医证候研究**

- 国家图书馆博士论文（fid=006367773）；246 例冠心病；24h 动态心电
- 方法：小波变换提取近似熵/关联维/复杂度；K-means 聚类分 10 类证
- 结果：实证组混沌程度最高、虚证组最低；一昼夜 HRV 非线性指标有周期性
- 用途：证型客观化方法学参考（非线性参数思路）

### #5 / #7 气虚→阳虚进展 HRV 递减（含健康对照）

**冠心病心衰患者中医证型与心率变异性、脑钠素及心功能关系的研究**（湖南中医药大学学报，150 例 CHF 5 型）  
**心力衰竭常见中医证型与心率变异性及心功能的相关性研究**（同刊，80 例 CHF + **20 健康对照** 4 型）

- 结果：HRV 从 心气阴虚 → 心气阳虚 → 气虚血瘀 → 阳虚水泛 → 心阳虚脱 依次降低（P<0.05/0.01）
- 用途：阳虚 HRV 低于气虚的排序锚点

### #6 慢性心力衰竭证型与 HRV 相关性（学位论文）

**慢性心力衰竭常见中医证型与心率变异性的相关性研究**

- 结果：SDNN/SDANN 随 气虚→阳虚 进展明显降低（气阴两亏 > 气虚血瘀 > 心肾阳虚 > 阳虚水泛）
- 用途：同 #5/#7

## 三、对 `estimate_tcm` 5 轴的校准建议（方向，非绝对值）

1. **qi_score（RMSSD→气虚）**：文献支持"RMSSD↓ ↔ 虚/瘀"，方向对。  
   但应更名为更诚实的「虚/瘀总体标记」，或叠加区分逻辑（见下）。
2. **liver_score（肝郁↔交感↑）**：#4 支持 气滞/肝郁 LF/LF-HF↑。但穿戴只给 RMSSD 时，  
   肝郁轴实际只能靠 recovery/sleep/mood 标签代理——需在设计文档标明「肝郁轴在仅有 RMSSD 时证据弱」。
3. **spleen_score**：文献无直接「脾虚↔特定 HRV」强证据（脾虚多靠症状/恢复率代理）。  
   应降级为「弱证据」，避免伪装成 HRV 可量化。
4. **新增建议（若未来有 LF/HF）**：阴虚/肝郁轴用 LF/HF 比 RMSSD 更特异——#3/#4 支持。
5. **绝对值**：现有 `qi_raw` 阈值（RMSSD 55/48/40/28 切点）是西方综述拍的，  
   宜用 #3 的排序（平和 29.6 / 气虚 26.4 / 阴虚 17.4）反向重设——但须先确认穿戴 RMSSD 与 Holter RMSSD 量纲一致。
