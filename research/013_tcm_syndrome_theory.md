# 013 · 中医症型理论层（TCM Syndrome Theory Layer）

> 状态：理论层 v0.1（仅文档，未改引擎）
> 目的：把 Hidden Chain 的中医症型模块从「HRV 相关映射」升级为「基于专业中医理论的辨证模型」的理论基础。
> **边界声明（必读）**：本层定义**来自标准中医教材的辨证理论**；HRV 仅作为部分辨证要点的**循证代理（proxy）**，输出必须称为「证候倾向性评估」，**不得称为诊断 / 辨证结论**。详见第 6 节合规红线。

---

## 0. 为什么需要这一层（问题陈述）

当前 `src/hrv_engine.py::TCMMetrics.from_hrv` 用 HRV 特征经分段线性公式给出 5 个证型分数，引用 Shaffer 2017 / NRICM 2010 / Olivera-Toro 2019 / Yang 2008。这些文献证明的是「HRV 与某证型相关」，但**证型本身的定义、鉴别、复合关系均缺失**——本质是「HRV ↔ 证型标签」的相关映射，不是中医辨证。

本层补上缺失的「中医辨证理论」，并把「理论（权威源）」与「HRV 代理（研究证据）」显式分离，便于后续引擎重构为 `tcm_theory`（零 HRV）+ `tcm_hrv_estimator`（带证据等级），契合项目「便于审计」主旨。

## 1. 理论权威源（Authority）

- 《中医诊断学》（全国高等中医药院校规划教材，第十版 / 十三五）——辨证要点、舌脉、临床表现的主要权威源。
- 《中医基础理论》（同上）——脏腑生理功能、气血津液、病因病机。
- 参考：中医临床诊疗术语 / 中医证候诊断标准（GB/T 16751 系列）、WHO 传统医学 ICD-11 模块。
- HRV ↔ 证型证据：仓库 `research/006_TCM-pattern-HRV-quantification.md`、`research/011_cn_tcm_hrv_studies.md`（含 NRICM 2010、Olivera-Toro 2019、Yang 2008 等）。

## 2. 辨证框架（Framework）

真实中医靠**分层框架**辨证，而非并列打分会：

1. **八纲辨证**（总纲）：阴阳、表里、寒热、虚实。
2. **气血津液辨证**：气（虚 / 滞）、血（虚 / 瘀 / 热 / 寒）、津液（亏虚 / 痰饮 / 水湿）。
3. **脏腑辨证**：肝、脾、心、肾、肺等脏腑功能失调。
4. **病因辨证**：七情（怒伤肝、思伤脾、喜伤心）、饮食劳逸、六淫。

本项目的 5 个引擎输出应映射到上述框架：
- 气血不足 → 气血津液 + 气虚
- 肝郁气滞 → 脏腑（肝）+ 病因（七情）
- 脾虚 → 脏腑（脾）
- 痰气互结 → 气血津液（痰）+ 脏腑（肝）
- 阴阳平衡 → 八纲（阴阳）

## 3. 证型目录（Syndrome Catalog）

对每个证型给出：中医定义、**辨证要点**（教材原汁）、临床表现、舌脉、病因病机、**HRV 可代理性（证据分级）**、鉴别诊断。

### 3.1 气血不足（气血两虚）

- **定义**：气虚 + 血虚同病，气血互根失调。
- **辨证要点**：神疲乏力，气短懒言，面色淡白或萎黄，头晕目眩，心悸失眠，舌淡嫩，脉细弱。
- **临床表现**：少气懒言，自汗，手足麻木，月经量少色淡，心悸健忘。
- **舌脉**：舌淡嫩、苔薄白；脉细弱。
- **病因病机**：先天不足 / 久病 / 劳倦 / 失血 → 气血生化不足，推动濡养失职。
- **HRV 代理性**：RMSSD 低于同龄正常值（Shaffer 2017 人群常模：20s≈55ms、30s≈48ms、40s≈40ms、50s≈32ms、60s≈28ms）可作「气虚推动无力」的 proxy，置信度 **中**；RHR 偏高可作「血虚 / 阴虚倾向」弱 proxy，置信度 **弱**。**HRV 无法代理面色 / 舌淡 / 心悸等核心要点。**
- **鉴别诊断**：与「单纯气虚」（无血虚象）、「单纯血虚」（无气短乏力）区分；与「阳虚」（畏寒肢冷明显）区分。

### 3.2 肝郁气滞（肝气郁结）

- **定义**：肝失疏泄，气机郁滞。
- **辨证要点**：情志抑郁，胸胁、少腹胀痛，善太息，脉弦。
- **临床表现**：胸闷嗳气，妇女乳房胀痛、月经不调、经前烦躁；或咽喉异物感（梅核气）。
- **舌脉**：苔薄白；脉弦。
- **病因病机**：七情所伤（情志不遂、郁怒）→ 肝失条达，气机不畅（木郁）。
- **HRV 代理性**：自主神经（肝主疏泄的现代对应 ≈ 整体气机 / 自主神经张力）异常——HRV 偏低、恢复慢（vagal reactivation 慢）、HRV 日间波动大，可作 proxy，置信度 **中-强**（NRICM 2010：肝郁型 vagal 下降最显著）。情绪标签（irritable / anxious）可作「七情病因」弱 proxy，置信度 **弱**。**HRV 无法代理胁胀 / 太息 / 脉弦等核心要点。**
- **鉴别诊断**：与「肝火上炎」（伴口苦、面红、易怒实火）、「肝胆湿热」（苔黄腻、口苦尿黄）区分；与「肝阳上亢」（头晕目眩、面红升火）区分。

### 3.3 脾虚（脾气虚 / 脾阳虚）

- **定义**：脾失健运，气血生化不足。
- **辨证要点**：食少纳呆，腹胀便溏，肢体倦怠，神疲乏力，面色萎黄，舌淡苔白，脉缓弱。
- **临床表现**：大便溏薄，食后腹胀，消瘦或肥胖（痰湿），水肿，少气懒言。
- **舌脉**：舌淡胖、边有齿痕、苔白腻；脉缓弱或濡。
- **病因病机**：饮食不节、劳倦、思虑过度（思伤脾）→ 脾失运化，气血生化之源不足，「脾为后天之本」「脾主升清」失职。
- **HRV 代理性**：整体自主神经张力低下——SDNN / HF 降低、LF/HF 升高、恢复速率慢，可作 proxy，置信度 **中**（Olivera-Toro 2019：脾虚 → SDNN↓17%、HF↓14%、LF/HF↑22%，疲劳↑21%、注意力↓16%）。疲惫 / 脑雾标签弱 proxy，置信度 **弱**。**HRV 无法代理食少便溏 / 舌淡齿痕等核心要点。**
- **鉴别诊断**：与「寒湿困脾 / 湿热蕴脾」（有实邪、苔腻明显）区分；与「肾虚」（腰酸耳鸣、五更泄）区分；与「气血不足」常相兼（脾气虚 → 气血生化不足 → 气血两虚）。

### 3.4 痰气互结 / 痰浊（Phlegm-Turbidity）

- **定义**：气滞津凝为痰，痰气互结，或痰浊内盛蒙蔽清窍。
- **辨证要点**：咽中如有物阻（梅核气），胸胁满闷；或形体肥胖、苔腻、脉滑；痰浊蒙窍则头晕昏蒙、困重。
- **临床表现**：咯痰、胸闷、恶心、嗜睡、思维迟钝（脑雾）。
- **舌脉**：舌淡胖、苔腻；脉滑。
- **病因病机**：七情不遂 + 饮食肥甘 → 气滞津停为痰，痰气互结于咽喉 / 胸膈；或痰浊上蒙清窍。
- **HRV 代理性**：严重自主神经抑制（Yang 2008：肝郁痰阻型 vagal 下降最严重）+ 周期校准后仍异常波动，可作 proxy，置信度 **弱-中**。脑雾 + 疲惫标签弱 proxy。**HRV 无法代理苔腻 / 脉滑 / 咽中异物感等核心要点。**
- **鉴别诊断**：与「单纯肝郁」（无痰象）、「痰湿壅肺」（咳喘痰多）区分；与「饮证 / 水湿」（形肿、小便不利）区分。

### 3.5 阴阳平衡（八纲总纲）

- **定义**：阴阳失调的总体现，项目以「平衡指数」表达。
- **阴虚辨证要点**：五心烦热，潮热盗汗，口干咽燥，舌红少苔，脉细数。
- **阳虚辨证要点**：畏寒肢冷，神疲嗜睡，面色㿠白，舌淡胖，脉沉微。
- **病因病机**：久病、劳倦、七情、年老 → 阴阳偏衰。
- **HRV 代理性**：阴虚多交感偏亢（RHR↑、应激反应强）；阳虚多整体低下（HRV 低、RHR 偏低或正常低值），置信度 **弱**。HRV 难以区分阴虚 / 阳虚明细，仅能作总体失衡 proxy。
- **鉴别诊断**：阴阳两虚（既有畏冷又有烦热）、亡阴亡阳（急危，不在本项目范围）。

## 4. 复合证型（Composite Patterns）

真实患者多为兼证，引擎当前 5 分数独立、无复合逻辑，是重大缺口。

- **肝郁脾虚**（木克土，最常见于现代压力人群）：肝郁（胁胀、情绪抑郁）+ 脾虚（食少便溏、乏力）。HRV 可同时见疏泄异常 + 运化低下。
- **心脾两虚**：心血虚（心悸失眠健忘）+ 脾气虚（食少乏力）。
- **痰气郁结**：见 3.4（梅核气），常由肝郁发展。
- **肝肾阴虚**：腰酸耳鸣 + 五心烦热，多见于阴虚体质。
- **肝胆湿热**：胁痛口苦、苔黄腻（急实证，本项目多作排除 / 警示）。

**建议**：引擎后续以「主证 + 兼证」结构输出，而非 5 个独立分数。

## 6. 合规与边界声明（Compliance — 红线）

1. 本模型输出必须称为「**基于 HRV 的中医证候倾向性评估**」，**不得**称「中医诊断」「辨证结论」「症型确诊」。
2. HRV 仅覆盖四诊（望闻问切）中「脉 / 神 / 整体气机」之一小部分，且为 proxy 非诊断；舌象、面色、问诊情志、闻诊均不可由 HRV 得出，必须在输出中标注「未采集」。
3. 涉及 3 名真实用户数据：须知情同意 + 匿名 ID，健康数据按敏感个人信息治理；输出仅面向用户本人，不得对外作医疗宣称。
4. 证据分级标注：强 / 中 / 弱，低证据项须在 UI / 报告中显式降级提示。
