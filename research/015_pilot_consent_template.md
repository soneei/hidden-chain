# 小规模试点知情同意与数据使用说明
## (Pilot Informed Consent & Data Use — Hidden Chain HRV-TCM)

> **文档类型**：知情同意模板  
> **适用范围**：Hidden Chain 3 用户 × 7 天 HRV 数据采集试点  
> **版本**：v1.0 / 2026-07-28

---

## 一、试点目的

Hidden Chain 是一个 **基于穿戴式 HRV 的中医证候倾向性分析引擎**（非诊断工具）。本次小规模试点（3 用户 × 7 天）的目的是：

1. **验证引擎**：真实 HRV 数据输入后，5 轴证候分数、复合证型识别、报告层输出的合理性。
2. **收集反馈**：用户对报告可读性、准确度、中医术语理解度的反馈。
3. **迭代准备**：为更大规模验证（如 30 人对照）做数据格式和管线准备。

**本次试点不输出任何医学诊断，不替代面诊。**

---

## 二、采集什么数据

### 从穿戴设备采集的 HRV 数据（自动记录，无需手动输入）：

| 字段 | 说明 | 示例 |
|---|---|---|
| resting_rmssd | 静息 RMSSD (ms)，心率变异性时域指标 | 35.2 |
| normalized_hrv | 周期校准后的标准化 HRV | 0.8 |
| recovery_classification | 恢复分类（fast/normal/slow） | slow |
| recovery_rate | 恢复速率 (ms/min) | 1.2 |
| resting_hr | 静息心率 (bpm) | 72.0 |
| sleep_hours | 前一晚睡眠时长（小时） | 6.5 |

### 用户自主上报的定性标签（可选）：

| 字段 | 说明 | 示例 |
|---|---|---|
| mood_tags | 当日情绪标签（多选，分号分隔） | irritable;anxious |

### **不会采集的数据：**

- 真实姓名、身份证号、手机号、住址
- 面部照片、舌苔照片
- 病历、用药记录、诊断史
- 任何可定位到个人的生物识别信息

---

## 三、匿名化规则

| 匿名 ID | 说明 |
|---|---|
| **U01 / U02 / U03** | 每个用户分配一个固定匿名 ID |
| 无姓名映射 | 匿名 ID 与真实身份的映射表不存入代码仓库，由负责人离线保管 |
| 报告命名 | 报告文件名为 `pilot_reports/U01/day1.md` 等，不含真实姓名 |

---

## 四、数据用途与存储

| 用途 | 说明 |
|---|---|
| **引擎验证** | HRV 数据输入引擎，检查 5 轴分数/主证/兼证/报告的合理性 |
| **迭代** | 根据用户反馈调整阈值、文案、报告模板 |
| **展示（内部）** | 生成去识别的汇总图表供团队讨论 |

**存储位置与安全：**
- 原始 CSV 存放于 `data/pilot/`（本地，不入 Git 仓库，已在 .gitignore 中排除）
- 生成的 Markdown 报告存放于 `.workbuddy/pilot_reports/`（本地，不推送）
- **数据不会上传任何云端服务、不会邮寄给第三方、不会用于训练 AI 模型**

---

## 五、用户权利

1. **随时退出**：任何时候都可以要求停止参与，已采集的数据全部删除，不影响任何关系。
2. **查看自己的数据**：可以随时查看自己原始 CSV 行和生成的报告。
3. **要求删除**：试点结束后或中途退出，可以要求删除全部个人数据。
4. **匿名保证**：所有对外展示的输出（如图表、统计）均基于 U01/U02/U03 匿名 ID，不显示真实身份。

---

## 六、风险与局限说明

- **本工具不是医疗器械**，不提供中医诊断或治疗建议。
- 报告中的「证候倾向性」仅基于 HRV 指标，**无法替代舌诊、脉诊、问诊**——标「需面诊」的条目务必寻求执业中医师判断。
- 如报告引发不适或焦虑，请立即停止使用并告知负责人。
